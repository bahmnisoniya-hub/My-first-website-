# Nova — Responsive Website Starter

A simple responsive landing page built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page structure and content (Home, About, Contact).
- `style.css` — visual design, responsive layouts, animations, and reduced-motion support.
- `script.js` — mobile navigation, scroll reveal, and demo contact-form interaction.

## Run locally
Open `index.html` in a browser. No build tools or package installation are required.

## Notes
- The contact form is a front-end demo only. It does not send email or store submissions.
- Google Fonts are loaded from the internet; system fonts are used as fallbacks.
- Customize the text, colors, and brand name in the files.
